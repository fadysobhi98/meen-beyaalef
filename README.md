# مين بيألف؟

Experimental Arabic bluffing trivia for 3 to 8 trusted friends. Host keeps the page open and screen awake. Prefer the same Wi-Fi. Strict NAT or isolated networks can prevent joining. No guaranteed background hosting or host migration.

Each player submits an answer, then votes among mixed answers and truth. Correct vote: +1. Each vote for a bluff: +1 to its author. True submitted answer: +1. Duplicate options merge. Own-option votes blocked. Two-team totals by default; individual and round-count modes available. 50 sourced questions.

Public static app, not cheat-proof. Do not enter personal information. The host keeps a session-local checkpoint. No independent game backend. Uses the free PeerJS signaling service and WebRTC.
